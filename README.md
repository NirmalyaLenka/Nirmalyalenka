## About Me

I build things that connect hardware and software.

- Embedded systems and firmware
- ESP32, Arduino, Raspberry Pi, Linux
- Sensor integration: I2C, SPI, UART, MQTT, BLE, Wi-Fi
- Web + backend for dashboards and control panels
- I like practical systems, not demo-only projects
