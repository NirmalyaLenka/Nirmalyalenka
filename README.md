# Nirmalya Lenka

**Engineering student | Embedded systems · IoT · Robotics · Software**

I build and document practical projects that connect firmware with sensors, actuators, and user-facing interfaces. Most of my hands-on work centers on ESP32/Arduino systems, I²C and UART peripherals, wireless communication, and small automation or robotics prototypes.

## Current focus

- **Embedded firmware:** C/C++, ESP32, Arduino, sensor integration, GPIO, I²C, UART
- **Connected systems:** Wi-Fi, BLE, ESP-NOW, lightweight HTTP/JSON interfaces
- **Monitoring and control:** OLED displays, web dashboards, thresholds, local automation
- **Robotics:** line-following and obstacle-detection prototypes
- **Software tooling:** Git, GitHub, Python and web technologies as project needs require

I distinguish implemented features from planned work and aim to document wiring, dependencies, file paths, limitations, and test status instead of presenting a prototype as production-ready.

This list describes areas I work with or explore; it is not a claim of equal proficiency across every technology.

## How I approach projects

1. Define the problem and the minimum working prototype.
2. Check pinouts, voltage limits, power requirements, and dependencies.
3. Keep firmware, wiring, BOM, and setup instructions aligned.
4. Test on the actual hardware where possible and record what was—and was not—verified.
5. Track limitations and next steps instead of hiding unfinished work.
