## `> whoami`

I am an engineering student focused on building systems where **code meets hardware**.

My work spans embedded firmware, sensor integration, wireless communication, automation, robotics and practical software tools.

I prefer building things that can be **tested on real hardware**, measured, debugged and improved instead of stopping at a software prototype.

